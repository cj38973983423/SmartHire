🤖 SmartHire

AI 智能招聘助手 —— 基于大语言模型的简历初筛系统，
帮助 HR 从海量简历中快速锁定高匹配度候选人

Python 3.11 React 18 FastAPI Ant Design 5 LLM-Powered SQLite
GitHub 仓库 → 📋 简历项目描述 📖 零基础教程

✨ 核心功能

📤

批量上传简历

支持 PDF/DOCX，多选文件或拖拽整个文件夹，上传即解析

🤖

AI 自动解析

自动提取姓名、技能列表、工作年限、教育经历等结构化信息

📋

JD 职位管理

创建职位描述，定义技能要求、经验年限、学历门槛，启停控制

🧠

AI 四维度评分

基于 JD 全文，从技能40% / 经验30% / 教育15% / 综合15% 综合打分

⭐

待筛选区 (≥60分)

高分候选人自动归类，按分数降序排列，优先查看

🗑️

淘汰库 (<60分)

低分候选人自动归入，HR 可人工复核、写备注

📊

数据看板

简历总数、各状态数量、平均评分，招聘进度一目了然

👨‍💼

人工决策

HR 标记通过 / 淘汰，支持添加备注，AI 辅助人工判断

🎯 AI 评分流程

📋 创建 JD → 📤 上传简历 → 🤖 AI 解析 → 🧠 四维度评分 → ⭐ ≥60 待筛选 or 🗑️ <60 淘汰库 → 👨‍💼 HR 决策
评分维度权重： ┌─────────────────┬──────┬──────────────────────────┐ │ 维度 │ 权重 │ 说明 │ ├─────────────────┼──────┼──────────────────────────┤ │ 技能匹配度 │ 40% │ 候选人技能与 JD 的匹配度 │ │ 经验匹配度 │ 30% │ 工作经验与要求契合度 │ │ 教育背景匹配度 │ 15% │ 教育背景符合程度 │ │ 综合契合度 │ 15% │ 整体素质与职位匹配度 │ └─────────────────┴──────┴──────────────────────────┘ 总分 = 技能 × 40% + 经验 × 30% + 教育 × 15% + 综合 × 15%

🔌 API 接口一览

方法路径功能
POST/api/resumes上传单份简历
POST/api/resumes/batch批量上传简历
GET/api/resumes简历列表（搜索/筛选/分页）
GET/api/resumes/{id}简历详情
PATCH/api/resumes/{id}/status更新简历状态+备注
DELETE/api/resumes/{id}删除简历
POST/api/jds创建 JD
GET/api/jdsJD 列表
GET/api/jds/{id}JD 详情
PUT/api/jds/{id}更新 JD
DELETE/api/jds/{id}删除 JD
POST/api/analyze/scoreAI 评分（单份）
POST/api/analyze/score-batch批量 AI 评分
GET/api/analyze/scores/{id}评分历史
GET/api/health健康检查
GET/api/stats仪表盘统计

Swagger UI: http://localhost:8000/docs

🚀 快速开始

前提条件：Python 3.10+ / Node.js 18+ / Hermes Agent

# 1. 克隆项目 git clone https://github.com/cj38973983423/SmartHire.git cd SmartHire # 2. 启动后端 cd backend python3 -m venv .venv source .venv/bin/activate pip install -r requirements.txt uvicorn app.main:app --reload --port 8000 # 3. 新开终端，启动前端 cd frontend npm install npm run dev # 4. 浏览器打开 http://localhost:5173
